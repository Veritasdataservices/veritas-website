VDS School Management System

A suite of five purpose-built desktop applications, Administration, Finance, Academics, Management, and Human Resource, sharing a single backend so a school's records stay consistent across every department.

Each application is designed to work offline-first, with records syncing across the suite through a unique key generated at setup, and a nightly backup routine so records are never dependent on a single machine or connection.

This system is currently in active development and has not yet been released. It is being built and tested before being offered to schools as a client deployment.

How It's Being Built

Five Linked Apps
Administration, Finance, Academics, Management, and HR: one shared record system
Offline-First
Built to keep working reliably without a constant internet connection
Centralised Access
Password and access management handled in one place, not scattered per app
Nightly Backup
Automatic Google Drive backup built in as standard disaster recovery
